## 3. How to run Godot

Use `.tools\godot-4.6.2\Godot_v4.6.2-stable_win64.exe`. It is a GUI binary, so
piping stdout gives an empty file — always pass `--log-file` and read that.

    & $godot --headless --path "<project>" --audio-driver Dummy \
        --log-file <log> -s res://scripts/tests/<test>.gd

Add `--check-only` for a parse check. Headless disables the team intro
(`_setup_team_intro`) unless you pass `--force-intro` after a `--` separator.
Headless **cannot render**, so it cannot catch z-order bugs — for anything
visual, drop `--headless` and park the window offscreen instead.

## 5. What this session shipped — sprite node rewrite, stage 1

The player asked, in their words, to "make every sprite a seperate node 2d".
Stage 1 is done, tested, and rendering correctly.

### The problem that had to be solved first

Child nodes of the runtime render **above** everything `main_runtime.gd::_draw()`
paints. Naively turning a tree into a `Sprite2D` put it on top of the HUD. That
is why only 4 things were ever nodes — all top-of-stack items.

The fix is a z-index band. The backdrop moved into its own canvas item, opening
negative z-indices between it and the runtime's drawing:

| Layer | z | Holds |
|---|---|---|
| `$GroundLayer` | -400 | Screen fill, ground tiles, waving grass, build grid |
| `$WorldSpriteLayer` sprites | -380…-320 | Converted world art |
| `$WorldSpriteLayer` own `_draw()` | -321 | Animal ground shadows |
| runtime `_draw()` | 0 | Everything unconverted, all HUD and menus |
| `$VisualLayer` | 0+ | Player, dealer, turrets, enemies (pre-existing) |

Pooled sprites use `z_as_relative = false` so their z is absolute.

### New files

- `scripts/world/sprite_pool.gd` — keyed pooled `Sprite2D` manager.
  `begin()` → `put` / `put_region` / `put_transformed` → `end()`. Same key across
  frames reuses the node; untouched ones are hidden and recycled. **This is what
  makes each remaining conversion ~15 lines instead of ~60.**
- `scripts/world/ground_layer.gd` — the backdrop. Holds what used to be
  `_draw_ground_area`, `_draw_waving_grass`, `_draw_grid` (deleted from runtime).
- `scripts/world/world_sprites.gd` — the converted art.
- `scripts/tests/world_sprite_nodes_test.gd` — guards that world art is nodes,
  that no world sprite can reach z >= 0 and cover the HUD, that the pool does not
  grow while idle, and that the menu retires sprites.

Both layers read runtime constants via `get_script_constant_map()` instead of
duplicating literals.
